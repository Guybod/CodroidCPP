 Codroid SDK 是一个用于机械臂远程控制的跨平台 C++ 开发工具包。它通过 TCP 通信协议实现与机器人的交互，涵盖了运动控制（mov\+J/mov\+L/mov\+C）、\+IO 管理、寄存器操作、数据流订阅及实时控制等核心功能。\hypertarget{index_autotoc_md1}{}\doxysection{🌟 特点}\label{index_autotoc_md1}

\begin{DoxyItemize}
\item $\ast$$\ast$开箱即用$\ast$$\ast$：底层依赖库（\+Asio 和 nlohmann/json）已内置于 {\ttfamily third\+\_\+party} 文件夹中，克隆仓库后无需额外安装系统依赖即可直接编译。
\item $\ast$$\ast$双通道架构$\ast$$\ast$：支持独立的指令通道与状态订阅通道，确保高频运动指令下发与实时状态反馈互不干扰。
\item $\ast$$\ast$单位标准化$\ast$$\ast$：\+SDK 内部已自动完成单位换算。
\begin{DoxyItemize}
\item $\ast$$\ast$长度单位$\ast$$\ast$：毫米 (mm)
\item $\ast$$\ast$角度单位$\ast$$\ast$：角度 (deg)（机器人返回的弧度数据已在内部自动转换为角度，并保留 3 位小数）。
\end{DoxyItemize}
\item $\ast$$\ast$跨平台兼容$\ast$$\ast$：完美支持 Linux (GCC) 与 Windows (Visual Studio / MSVC) 编译环境。
\end{DoxyItemize}\hypertarget{index_autotoc_md2}{}\doxysection{📁 项目结构}\label{index_autotoc_md2}

关键文件：\+Codroid.\+dll (运行时必须), Codroid.\+lib (编译链接必须)。\hypertarget{index_autotoc_md6}{}\doxysection{💻 如何在您的项目中使用}\label{index_autotoc_md6}
由于本 SDK 未采用 PIMPL 模式隐藏底层依赖，在您的第三方 C++ 项目中引入本 SDK 时，请务必进行以下配置：

1.包含目录 (Include Directories)

将以下两个路径添加到您的项目包含路径（\+Include Path）中：
\begin{DoxyItemize}
\item Codroid\+SDK/include
\item Codroid\+SDK/third\+\_\+party (由于头文件嵌套，必须包含此路径，否则找不到 asio.\+hpp)
\end{DoxyItemize}

2.预处理器定义 (Preprocessor Definitions)

必须添加以下宏定义：
\begin{DoxyItemize}
\item ASIO\+\_\+\+STANDALONE (告诉 Asio 使用标准版而非 Boost 版)
\end{DoxyItemize}

3.\+Windows 环境额外配置


\begin{DoxyItemize}
\item 链接库：将 Codroid.\+lib 添加到链接器的附加依赖项。
\item 字符编码：建议开启 /utf-\/8 编译选项，以确保中文注释不会引起编译语法错误。
\item 运行时：程序运行时必须将 Codroid.\+dll 放置在与 .exe 文件相同的目录下。
\end{DoxyItemize}\hypertarget{index_autotoc_md7}{}\doxysection{🚀 快速上手示例}\label{index_autotoc_md7}

 \hypertarget{index_autotoc_md8}{}\doxysection{⚠️ 注意事项}\label{index_autotoc_md8}

\begin{DoxyEnumerate}
\item 状态同步延迟：受限于机器人端状态推送固定为 1 秒/次，\+Wait 系列阻塞函数在判断机器人停止时可能会存在最高 1 秒的自然同步延迟。
\item 空数组崩溃预防：\+SDK 内部实现了防御性编程，发送指令时会自动剔除空的 coor 或 tool 数组字段，以规避机器人后端处理空数组时的崩溃 Bug。
\item 多线程安全：send\+Command 内部已通过 std\+::mutex 加锁。支持在多线程环境下并发调用非阻塞运动指令，但建议在同一时刻只由一个线程控制机器人运动。
\item 单位验证：请注意，机器人推送的 joint 数据在 SDK 内部被视为角度（\+Degrees）。若您的机器人固件返回的是弧度，\+SDK 将按照 1rad ≈ 57.\+295deg 进行自动转换。 
\end{DoxyEnumerate}
